# 014 — PWA : manifeste, service worker, installation

**Ce que ça livre :** la transforme de l'app en **PWA installable** : manifeste
web app, service worker, icônes, installation depuis le navigateur (NFR-PWA-1),
pages statiques lisibles sans JavaScript (NFR-PWA-2) et respect strict du mode
hors-ligne : **aucun prix périmé n'est servi hors-ligne** — les prix viennent
toujours du serveur, seul le profil/favoris (localStorage) fonctionnent sans
réseau (NFR-PWA-3, spec §2.2).

**Bloqué par :** 010 (page principale), 013 (profil/favoris en localStorage).

**Statut :** ready-for-agent

- [ ] Manifeste web app (nom, short_name, icônes 192/512, couleurs de thème,
      display standalone) ; installation possible depuis le navigateur.
- [ ] Service worker enregistré ; stratégie de cache cohérente (app shell
      statique en cache, données prix **jamais** en cache hors-ligne).
- [ ] L'application se charge et s'affiche hors-ligne avec l'app shell et les
      données locales (profil, favoris) ; une demande de prix hors-ligne affiche
      un état d'erreur explicite (« données en cache (date) » ou « données
      insuffisantes »), jamais un prix périmé (NFR-PWA-3, §13 #18).
- [ ] Pages statiques (mentions, erreurs, structure) lisibles sans JavaScript
      (NFR-PWA-2).
- [ ] Vérifié avec Playwright/Lighthouse : installabilité (manifeste + SW valides)
      et rendu sans JS des pages statiques.
- [ ] `npm run lint && npm run typecheck && npm run test` passe.
